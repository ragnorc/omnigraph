## Lessons from earlier runs

This was the first run of the workflow. No earlier run, trace or false alarm existed. The run therefore spread its time over all journeys and spent the most on query semantics, merges and change feeds, where a wrong answer is silent.

## Issues filed

| Issue | Finding | Severity |
|---|---|---|
| [#1277](https://github.com/ModernRelay/omnigraph/issues/1277) | A negated or OR-ed pair of disjoint `in` tests on a nullable property returns, deletes and updates rows whose value is null. The cause is DataFusion 54's `inlist_intersection` and `inlist_except` rewrites, applied by Lance's filter planner. | High: wrong rows and silent deletes |
| [#1278](https://github.com/ModernRelay/omnigraph/issues/1278) | A `merge` load or keyed `insert` that omits a property sets it to null, Blob payloads and vectors included. The docs say only "updates". | Medium to high: silent loss of stored values |
| [#1279](https://github.com/ModernRelay/omnigraph/issues/1279) | GQ has no negative number literal and no `U64` literal above the I64 range. | Medium: constants need a parameter |
| [#1280](https://github.com/ModernRelay/omnigraph/issues/1280) | A served `cluster apply` that fails schema preflight closes the graph to reads and writes, sends `Retry-After: 60`, and reports `effects: unknown`. | Medium to low: availability and retry guidance |
| [#1281](https://github.com/ModernRelay/omnigraph/issues/1281) | A GQ parse error on a direct target reports `action: refresh` with no code. The served path reports `bad_request` and `fix`. | Low: wrong retry guidance |

The GQT cases for #1277, #1278 and #1279 are in [tools/stress/repros/](../../tools/stress/repros/). They fail on the base commit.

The run did not test injected storage latency (ThrottledStore), toxiproxy, or large-scale history. Docker is not available on the host. The run used a Python TLS proxy for lost-answer faults instead.

## Coverage gaps for the next run

- Embeddings: no provider credentials on the host, so `@embed` and text `nearest` were not tested.
- Storage faults below the object store: ThrottledStore, a failing object-store wrapper and toxiproxy in front of RustFS.
- Scale: deep history (thousands of commits), many branches, and wide rows.
- Cleanup during long reads (open as #958) and MCP.
